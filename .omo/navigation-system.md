# Система навигации Awesome AI Handbook

## Трёхуровневая архитектура

### Уровень 1: Глобальный (README)
**Файлы:** `README.md`, `README.ru.md`

Содержит:
- Переключатель языка (RU ↔ EN) в шапке
- Миссия (1–2 строки)
- Quick start (один блок кода, компактно)
- **Таблица разделов** (компактная, без дубликатов) — 5 разделов, каждая строка: название, ссылка на секцию, кол-во файлов, уровень, время
- Ссылка на **каталог файлов** (catalog.md)
- Структура проекта (схема, но компактнее)
- Футер: лицензия, контрибьютинг

### Уровень 2: Секционный (Section README)
**Файлы:** `section/README.md`, `section/README.ru.md`

Шаблон:
```markdown
# Title
> Description

[← Главная](../README.ru.md) · [🇬🇧 English](README.md)

---

## Содержание раздела

| Файл | О чём | Уровень | Время |
|------|-------|---------|-------|
| [page1](page1.ru.md) | Описание | 🟢 | 5 мин |

---

## Связанные разделы

- [Раздел 1](../section1/README.ru.md) — описание
- [Раздел 2](../section2/README.ru.md) — описание

---

**Навигация:** [← На главную](../README.ru.md)
```

### Уровень 3: Страница
**Файлы:** все `.md` / `.ru.md` кроме README

Шаблон:
```markdown
# Title
> Description

[← Название раздела](README.ru.md) · [Next →](next-page.ru.md)

---

## Content
...

---

## Что дальше

| Если хотите | Переходите |
|-------------|-----------|
| ... | ... |

---

**В разделе:** [page1](page1.ru.md) · [page2](page2.ru.md) · [page3](page3.ru.md)  
**Связанные разделы:** [section1](../section1/) · [section2](../section2/)  
**Навигация:** [← Раздел](README.ru.md) · [↑ На главную](../README.ru.md) · [🇬🇧 English](page.md)
```

### Root-страницы (SECURITY, CONTRIBUTING, CODE_OF_CONDUCT)

Шаблон:
```markdown
# Title

[← Awesome AI Handbook](../README.ru.md)
...
**Навигация:** [← На главную](../README.ru.md)
```

---

## Правила

1. **Каждая страница** имеет ссылку «на уровень выше» (↑ breadcrumb)
2. **Каждая страница** имеет ссылку на английскую/русскую версию (кроме корневых README — у них переключатель в шапке)
3. **Секционные README** содержат полный список файлов раздела
4. **Страницы** содержат «В разделе» (соседние файлы) + «Связанные разделы» (кросс-ссылки)
5. **Без дублирования** — README не повторяет таблицу разделов дважды
6. **Каталог файлов** — отдельный файл `catalog.md` / `catalog.ru.md` со всеми 52 файлами (плоский список)
