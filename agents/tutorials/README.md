## Prerequisites

Make sure you have:
1. Ollama installed — [local-models/getting-started.md](../../local-models/getting-started.md)
2. Model `qwen3.5:4b` pulled — `ollama pull qwen3.5:4b`
3. Python 3.10+ with `pip install requests`
