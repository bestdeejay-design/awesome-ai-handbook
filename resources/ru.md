## How to Add a Resource

1. Ensure the resource is active (posts within last 3–6 months)
2. Add a row to the appropriate section
3. Include `last-verified: YYYY-MM-DD`
4. Open a PR

Entry format:

```markdown
- **[Name](URL)** — brief description. `last-verified: 2026-07-24`
```
