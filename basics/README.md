## Three Learning Paths

### 🟢 Quick Start (5 min)

"Just want to try it — no terminal, no setup."

| Step | What To Do |
|------|-----------|
| 1 | [What is AI and why it matters](what-is-ai.md) |
| 2 | Install **LM Studio** ([lmstudio.ai](https://lmstudio.ai)) — a GUI app with buttons |
| 3 | Download Qwen 3.5 4B directly inside LM Studio |
| 4 | Start chatting — free, local, no cloud |

| Step | Where To Go | Time |
